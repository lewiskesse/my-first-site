# My First HTML Website

## About the Project

My First HTML Website is a beginner web development project created by Lewis Kesse, an Information Technology student at the University of Professional Studies, Accra (UPSA).

The project is designed to introduce me to the fundamentals of web development through practical experience with HTML5.

## Project Objectives

- Understand the basic structure of an HTML document.
- Learn how to use HTML tags and elements.
- Practise creating headings, paragraphs and lists.
- Learn how to add images and hyperlinks.
- Understand how to organise content on a webpage.
- Develop practical web development skills.

## Technologies Used

- HTML5

## Project Type

Beginner Web Development Project

## Purpose

The purpose of this project is to apply the HTML concepts I learn in class and develop my skills through hands-on practice.
